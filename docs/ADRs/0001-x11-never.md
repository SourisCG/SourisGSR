# ADR-0001 — No X11 support, permanently (`DEVIATION-X11-NEVER`)

Status: accepted (user decision).

## Context

The C original supports X11 capture paths (`xcomposite`, `ximage`,
`nvfbc`, `window/x11`, `screen-direct`, `focused`, raw window ids,
`-oc` overclocking via `libXNVCtrl`).

## Decision

SourisGSR targets Linux Wayland-only plus Windows. Every X11-only source
and flag parses but fails with localized `err_unsupported_x11`. No X11
dependency may enter the build, now or later.

## Consequences

- `-w screen-direct/-force`, `-w focused`, raw window ids (hex or decimal,
  mirroring `contains_non_hex_number`), and `-oc` effects are rejections,
  covered by CLI parity tests.
- Damage backend is KMS/portal metadata only; the X11 damage path was not
  ported.

# Support

- Officially supported: Linux Wayland (GNOME, KDE Plasma, Hyprland) + Windows 11 22H2+.
- Best-effort / WONTFIX: X11, Windows 10. Report with OS, compositor/driver, Wayland/Win11 repro.
- Audio/volume is recording-only. "System doesn't sound louder" is expected.
- Upstream bugs reproducing on pure `dec05eba` should also go upstream.
